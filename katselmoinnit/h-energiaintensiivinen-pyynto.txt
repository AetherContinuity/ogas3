## Energiaintensiivinen kasvu ja julkinen talous — ennakkokirjaus H, rinnakkaislaskenta hankkeen vaiheen mukaan (17.11.2026)

G pysyy muuttumattomana historiallisena kirjauksena. H on uusi laskentakierros G:n toteutusselosteen kohdan 4 pohjalta. Luonnosta kommentoivat ChatGPT ja Marko; Markon ratkaisu: **rinnakkaislaskenta, vaihtoehdot mukaan**.

**1. Kysymys ja nimitys.** Kuinka paljon energiaintensiivinen kasvu kasvattaa julkisyhteisöjen (S13) tuloja 2030 suhteessa VM:n perusuraan, kun hankkeet otetaan mukaan vain dokumentoidun vaiheensa mukaan? Tulos on **osittainen fiskaalinen vaikutus**, ei nettovaikutus: siitä puuttuvat sähkön hintavaikutus, syrjäytyminen ja verkkokustannukset. Matriisin solu yhdistää datakeskus- ja P2X-kulutuksen laskennallisesti; se ei väitä, että molemmat toteutuisivat ilman sähköjärjestelmän muita muutoksia.

**2. Datakeskusten taso 2030 (rinnakkaiset vaihtoehdot, ei todennäköisyysjakauma).** Lähteet luokitellaan alkuperän mukaan; samaa lukua toistavat lähteet ovat yksi taso.

- D1 5–6 TWh — Datakeskusten kansallinen tiekartta (VN:n selvityshenkilö); toistettu HE 282/2026:ssa ja FDCA:n tiedotteessa 4/2026. Daily Finland ei ole itsenäinen lähde.

   1  """Ennakkokirjaus H: osittainen fiskaalinen vaikutus julkisyhteisöihin 2030,
   2  rinnakkaislaskenta (datakeskustaso D × hankevaihe P × ajoitus × oletukset).
   3  Säännöt: SEURANTA.md, H ja lisäys 1 (jäädytys 17.11.2026). Vain vakiokirjasto.
   4  [M] lähde, [L] laskettu, [A] oletus."""
   5  import itertools, json
   6  
   7  H = 8760
   8  H2 = 55.0                                   # MWh/t H2 [A] (G lisäys 2)
   9  D0 = 3.8                                    # TWh, perusura
  10  DC_TASOT = {"D0 TEM": 3.8, "D0b Statnett": 4.0, "D1a tiekartta": 5.0, "D1b tiekartta": 6.0,
  11              "D2a ET": 11.0, "D2b ET": 18.0, "D3 SM-022": 17.5}
  12  
  13  # Hankeliite (lisäys 1). cod2030 = käyttöönotto 2030 -> ajoituskerroin t
  14  def hankkeet(cf):
  15      return [  # nimi, taso, TWh, hyvitys M€ (kohdistettu), työpaikat, cod2030
  16          ("Freija",      "P1", 160 * H * cf / 1e6,            110.6,       100, False),
  17          ("Arctic Sisu", "P1", 56.1e3 * H2 / 1e6 / 3,         150.0 / 3,   100, True),
  18          ("VolagHy",     "P1", 50e3 * 0.5 * H2 / 1e6,         150.0,       100, True),
  19          ("ETFuels",     "P2", 300 * H * cf / 1e6,            118.6,        60, True),
  20          ("Plug site 1", "P2", 87 * H * cf / 1e6,              44.2,        40, True),
  21          ("Plug site 2", "P2", 207 * H * cf / 1e6,            105.8,        94, True),
  22      ]
  23  TASOT = {"P0": [], "P1": ["P1"], "P2": ["P1", "P2"]}
  24  
  25  # Verot ja maksut [M]
  26  SV_I, SV_II, HVM = 22.4, 0.5, 0.85          # €/MWh
  27  YV_DC = 11.6e3 / (8760 * 0.8)               # €/MWh (SM-022 kululisämalli)
  28  YV_P2X_YLA = 18.9                           # €/MWh (verot_304 ryhmä 24)
  29  YV_VALTIO = 0.7715                          # jako 2026
  30  PALKKA = 60e3                               # € [A]
  31  PER_TP = {"valtio": 0.12 * PALKKA, "kunnat": 0.07 * PALKKA,
  32            "tyoelake": 0.244 * PALKKA,
  33            "muut_sosrahastot": (0.0123 + 0.0089 + 0.0191 + 0.0088) * PALKKA}
  34  
  35  def solu(dc_taso, p, t=0.5, nettouusi=0.5, yv_p2x=0.0, cf=0.6, dc_tp_per_twh=120):
  36      dDC = dc_taso - D0
  37      sek = {"valtio": 0.0, "kunnat": 0.0, "tyoelake": 0.0, "muut_sosrahastot": 0.0}
  38      # datakeskukset
  39      sek["valtio"] += dDC * (SV_I + HVM)
  40      yv = dDC * YV_DC
  41      sek["valtio"] += yv * YV_VALTIO; sek["kunnat"] += yv * (1 - YV_VALTIO)
  42      tp = dDC * dc_tp_per_twh
  43      # P2X
  44      p2x_twh = 0.0; hyv_vah = 0.0
  45      for nimi, taso, twh, hyv, tpp, cod30 in hankkeet(cf):
  46          if taso not in TASOT[p]: continue
  47          k = t if cod30 else 1.0
  48          if k == 0: continue
  49          e = twh * k
  50          p2x_twh += e
  51          sek["valtio"] += e * (SV_II + HVM)
  52          brutto = e * yv_p2x
  53          vah = min(brutto, 0.10 * hyv * k)       # hankekohtainen raja
  54          hyv_vah += vah
  55          netto = brutto - vah
  56          sek["valtio"] += netto * YV_VALTIO; sek["kunnat"] += netto * (1 - YV_VALTIO)
  57          tp += tpp * k
  58      for s in sek:
  59          if s in PER_TP: sek[s] += tp * nettouusi * PER_TP[s] / 1e6
  60      return {"sek": sek, "summa": sum(sek.values()), "p2x_twh": p2x_twh, "dDC": dDC,
  61              "tyopaikat": tp, "hyvitys_vahennys": hyv_vah,
  62              "menetetty_II": p2x_twh * (SV_I - SV_II)}
  63  
  64  def bkt_2030():
  65      b = 281.783e3
  66      for g in (0.008, 0.017, 0.017, 0.015, 0.015): b *= (1 + g) * 1.02
  67      return b
  68  
  69  if __name__ == '__main__':
  70      ERO = 0.014 * bkt_2030()
  71      print(f"Vertailuero ≈ {ERO:.0f} M€\n")
  72      print("PÄÄARVO (t 50 %, nettouusi 50 %, P2X-yhteisövero 0, käyttöaste 60 %, DC 120 tp/TWh), M€ / % vertailuerosta")
  73      print(f"{'':16}" + "".join(f"{p:>16}" for p in TASOT))
  74      rivit = []
  75      for dn, dv in DC_TASOT.items():
  76          cells = [solu(dv, p) for p in TASOT]
  77          print(f"{dn:16}" + "".join(f"{c['summa']:8.0f} {c['summa']/ERO:6.1%} " for c in cells))
  78      print("\nVÄLIT (kaikki yhdistelmät: t 0/50/100, nettouusi 0/50/100, yv 0/yläraja, cf 40/60/80, DC tp 120/400)")
  79      tulos = {}
  80      for dn, dv in DC_TASOT.items():
  81          rivi = []
  82          for p in TASOT:
  83              vals = [solu(dv, p, t, n, y, c, j)['summa'] for t, n, y, c, j in itertools.product(
  84                  (0, 0.5, 1), (0, 0.5, 1), (0, YV_P2X_YLA), (0.4, 0.6, 0.8), (120, 400))]
  85              pa = solu(dv, p)
  86              tulos[f"{dn}|{p}"] = {"paa": pa['summa'], "min": min(vals), "max": max(vals), "sek": pa['sek'],
  87                                    "p2x_twh": pa['p2x_twh'], "tyopaikat": pa['tyopaikat']}
  88              rivi.append(f"{min(vals):5.0f}–{max(vals):<5.0f}")
